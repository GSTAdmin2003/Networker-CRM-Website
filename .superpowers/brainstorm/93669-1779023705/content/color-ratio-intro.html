The 6·3·1 Color Ratio

Your site already has the right colors — this rule defines how much of each to use.

Visual proportion

60%
Dominant · Background
Paper, white, and neutral ink tones. Large surfaces — page background, cards, sections.
30%
Secondary · Depth
Navy blues for headings, dark sections (Problem, Waitlist), nav, and key UI elements.
10%
Accent · Action
Teal only for CTAs, highlights, icons, and interactive states. Used sparingly.

The main question: do you want to enforce this via semantic CSS tokens (rename variables to dominant/secondary/accent), or audit the visual layout and adjust where the ratio is off?
